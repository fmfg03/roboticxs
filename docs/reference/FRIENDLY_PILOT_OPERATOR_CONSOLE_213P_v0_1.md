# Friendly Pilot Operator Console v0 - 213P

213P adds local Telegram/admin pilot visibility commands:

- `/pilot_users`
- `/pilot_user <id>`
- `/pilot_health`

The console shows user alias, role, robot status, connector readiness, last activity, feedback count, blocked actions, unresolved setup issues, and usage/cost snapshot.

This is not a web console and does not provision users. It does not invite users, activate connectors, send Gmail, write Calendar, write CRM, use WhatsApp, mutate Memory Center, run background actions, deploy, push, merge, create PRs, or write externally beyond owner-requested Telegram replies.
