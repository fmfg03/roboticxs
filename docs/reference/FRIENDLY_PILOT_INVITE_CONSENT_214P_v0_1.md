# Friendly Pilot Invite & Consent 214P v0.1

214P adds local Telegram/admin invite and consent text through `/pilot_invite <alias>` and `/pilot_consent <alias>`.

The consent card explains what Roboticxs can read, what it cannot do, what requires approval, what is logged, how to stop the pilot, and how to correct or remove memory. It is deliberately not legal boilerplate and does not create a real invite, account, connector authorization, or pilot provisioning record.

Safety boundary: 214P is local text only. It does not send invites externally, activate connectors, provision users, send Gmail, modify Gmail, write Calendar events, write CRM records, access WhatsApp, mutate memory directly, perform destructive actions, deploy, push, merge, create PRs, or introduce 215P behavior.
