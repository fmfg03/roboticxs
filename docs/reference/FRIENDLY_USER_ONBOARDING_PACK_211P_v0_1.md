# Friendly User Onboarding Pack v0 - 211P

211P adds `/friendly_onboarding` for a controlled 1-3 friendly-user pilot setup pack.

The pack includes:

- setup checklist
- allowed commands
- blocked actions
- privacy and source trace explanation
- memory approval explanation
- daily usage script
- feedback commands
- stop conditions

This is onboarding guidance only. It does not invite users, provision accounts, activate connectors, send Gmail, write Calendar, write CRM, use WhatsApp, mutate Memory Center, run background actions, deploy, push, merge, create PRs, or write externally beyond owner-requested Telegram replies.
