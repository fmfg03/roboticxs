# Founder-to-Friendly Pilot Baseline v0 - 212P

212P adds `/friendly_pilot` as the controlled baseline from founder dogfooding to a 1-3 friendly-user pilot.

The baseline ties together:

- `/founder_loop`
- `/feedback`
- `/draft_revise`
- memory correction commands
- `/pilot_metrics`
- `/friendly_onboarding`

It requires visible receipts for source trace or fallback, feedback, draft revision, memory correction, usage/cost, and safety boundaries.

212P does not send Gmail, write Calendar, write CRM, use WhatsApp, mutate Memory Center, invite users, provision accounts, activate connectors, run background actions, deploy, push, merge, create PRs, or write externally beyond owner-requested Telegram replies.
