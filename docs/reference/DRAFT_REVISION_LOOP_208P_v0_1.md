# Draft Revision Loop v0 - 208P

208P adds safe local draft revision requests before approval, export, or Gmail draft creation.

The command is `/draft_revise <draft_id> <revision>`.

Supported revisions are `shorter`, `more_direct`, `warmer`, `spanish`, `add_context`, and `remove_claims`.

208P creates local revision candidates only. It does not send Gmail, create Calendar events, write CRM, use WhatsApp, bypass approval, mutate Memory Center, activate connectors, deploy, push, merge, create PRs, or write externally beyond owner-requested Telegram replies.
