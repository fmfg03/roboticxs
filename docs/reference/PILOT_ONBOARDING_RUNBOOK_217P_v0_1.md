# Pilot Onboarding Runbook 217P v0.1

217P adds `/pilot_runbook`, a local Telegram/admin runbook for executing a friendly pilot from Day 0 through Day 7.

The runbook covers setup, consent, allowlist, first daily loop, memory review, meeting prep, document review, draft/revision/approval, feedback, issue capture readiness, weekly report readiness, and the Day 7 decision. Each day includes a command, expected result, fallback status, and stop condition.

Safety boundary: 217P is local guidance only. It does not send invites, provision external accounts, activate connectors, send Gmail, modify Gmail, write Calendar events, write CRM records, access WhatsApp, migrate data, mutate memory directly, perform destructive actions, deploy, push, merge, create PRs, or introduce 218P behavior.
